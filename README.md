One pickup line, as if a vending machine were flirting with a passing human. The program scores ten fresh lines against the judge's brief — machine voice first, then the machine's own world of slots, buttons, coils and exact change, then the laugh — and writes the winner to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
